# NYX Distributed Worker Architecture Overview

## 1. Executive Summary
Phase 18 extends NYX into a **Distributed Worker Architecture**.
NYX can now manage remote worker nodes (`WorkerNode`) across multiple machines to execute approved specialized security research agent workloads while maintaining central orchestration, authorization enforcement, scope boundaries, and SHA-256 evidence integrity validation.

## 3. Core Security & Control Principles

1. **HMAC Signed Authentication**: Worker nodes authenticate using signed HMAC tokens generated from `WorkerSecurity`. Unauthenticated task execution is rejected.
2. **Centralized Mandatory Approval**: All active execution proposals generated by remote worker agents must receive explicit human sign-off prior to running.
3. **SHA-256 Evidence Verification**: Evidence artifacts (logs, outputs, screenshots) generated by remote worker nodes are validated against expected SHA-256 checksums before being accepted into the central Evidence Vault.
4. **Zero Reverse Imports**: `nyx/*`, `nyx/worker/*`, and `nyx/distributed/*` maintain strictly 0 imports from `nyx_cli.cli`.
