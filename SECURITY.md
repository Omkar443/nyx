# Security Policy for NYX

## Scope & Authorized Usage
NYX is designed for authorized security research, vulnerability assessment, and red-team operations within explicitly defined scope boundaries.

---

## Reporting a Security Vulnerability

If you discover a security vulnerability within NYX:
- **Do NOT** open a public GitHub issue.
- Email your findings directly to the maintainers at `security@nyx-engine.org`.
- Include step-by-step reproduction steps and impact details.

Maintainers will acknowledge receipt within 48 hours and work on a security fix.
